    Project

    About this project

    An early-warning system that predicts a student's final grade (0–20) with a neural network.

    Dataset

    UCI Student Performance (Math): 395 students, 29 input features covering family, study habits and lifestyle.

    Model

    Random Forest regressor (300 trees, settings chosen on a validation set) predicting the final grade. Compared against Linear Regression using MAE, RMSE and R².

    Evaluation

    70/15/15 split. Compared against a Linear Regression baseline using MAE, RMSE and R².

    Responsible use

    Predictions are estimates meant to start a supportive conversation, never to judge or label a student.
